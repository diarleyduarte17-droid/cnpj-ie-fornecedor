# CNPJ e IE de fornecedor

Utilitário de validação de CNPJ e composição de uma consulta completa de fornecedor. Separe claramente dado público, dado oficial da SEFAZ e ausência de resposta.

Uma IE retornada por fonte pública deve ser tratada como informativa; a validação fiscal depende da fonte oficial aplicável e de autorização.

```bash
npm install
npm run check
```

Abra [AGENTS.md](./AGENTS.md) para orientar a IA sobre integrações públicas e oficiais.

---

## 🇬🇧 English

**Supplier CNPJ and State Registration (IE).** Utility that validates Brazilian CNPJ numbers and builds a complete supplier lookup, clearly separating public data, official SEFAZ data and missing responses. An IE returned by a public source is informative only; fiscal validation depends on the applicable official source and authorization.

```bash
npm install
npm run check
```
